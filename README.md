# Python Pandas – Data Analysis Project

##  About the Project

This project focuses on learning and practicing **Python Pandas** for data analysis and manipulation. It covers essential Pandas functions with practical examples using a sample dataset.

The project is organized into separate sections to make learning, understanding, and executing the code easier.

##  Topics Covered

### Part 4: Selecting and Filtering Data
- Selecting single and multiple columns
- `loc[]` and `iloc[]`
- Conditional filtering
- Multiple conditions (AND, OR, NOT)
- `isin()`, `between()`, `query()`, `filter()`
- `select_dtypes()`

### Part 5: Data Cleaning and Preprocessing
- `isnull()` and `isna()`
- `notnull()`
- `dropna()` and `fillna()`
- Forward Fill and Backward Fill
- `duplicated()` and `drop_duplicates()`
- `replace()`
- `astype()` and `convert_dtypes()`
- `rename()` and `drop()`
- Handling Outliers using IQR Method

### Part 6: Data Manipulation and Transformation
- Adding, updating and deleting columns
- `insert()`
- `apply()` and `map()`
- `DataFrame.map()`
- `assign()`
- `where()` and `mask()`
- Lambda Functions
- Vectorized Operations

### Part 7: Sorting and Ranking
- `sort_values()`
- `sort_index()`
- `rank()`
- `nlargest()` and `nsmallest()`

### Part 8: GroupBy and Aggregation
- Understanding `groupby()`
- Grouping by one and multiple columns
- Aggregation Functions
- `agg()` and Named Aggregation
- `transform()`
- GroupBy `filter()`
- Custom Aggregation
- `reset_index()`

### Part 9: Combining Datasets
- `concat()`
- `merge()`
- Inner, Left, Right and Outer Joins
- Merging using multiple columns
- Self Join
- `join()`

### Part 10: Date and Time Operations
- `to_datetime()`
- Extracting Year, Month, Day and Weekday
- Date Filtering
- Date Differences
- `date_range()`
- Time Zones
- `resample()`
- `rolling()` and `shift()`

### Part 11: String Operations
- `str.lower()` and `str.upper()`
- `str.title()` and `str.strip()`
- `str.replace()`
- `str.contains()`
- `str.startswith()` and `str.endswith()`
- `str.split()` and `str.extract()`
- `str.len()`
- Regular Expressions (Regex)

### Part 12: Statistical Analysis
- `mean()`, `median()` and `mode()`
- `sum()` and `count()`
- `min()` and `max()`
- `std()` and `var()`
- `quantile()`
- `corr()` and `cov()`
- `cumsum()` and `cumprod()`
- `pct_change()` and `diff()`

1. Clone or download this repository.
2. Open the `.ipynb` notebook file.
3. Upload it to Google Colab.
4. Run the Setup cell first.
5. Execute each part separately from Part 4 to Part 12.
6. Observe and understand the outputs.
